Pregunta del reto

¿Qué herramientas estratégicas y metodológicas pueden implementarse en Seconecta S.A.S. para identificar oportunidades y establecer las bases de un proceso de internacionalización?

Las entregas de esta línea de tiempo son las herramientas con las que se responde: diagnóstico DPI+, modelo de negocio, DOFA, VRIO, matriz de brechas, lectura ESG, análisis de entornos comparado y selección del mercado con suma ponderada (WSM).

Las entregas siguientes se agregarán a esta línea de tiempo a medida que avance el proyecto.
